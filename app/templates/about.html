{{ _('How it works') }}

  1. {{ _('Collect. One collector per source, each on its own schedule, with conditional requests and deltas (no full re-downloads).') }}
  2. {{ _('Normalize & deduplicate. CVE, GHSA, PYSEC, GO and vendor IDs are merged into one record with aliases. Later facts (new CVSS, KEV listing, fixed versions) become events on the same record instead of duplicate posts.') }}
  3. {{ _('Filter. Only records that match the product catalog go further. The Linux kernel is included only for exploited or high-severity issues.') }}
  4. {{ _('Prioritize. A transparent rule combines vendor/CNA CVSS, CISA KEV and EPSS. CVSS is never invented: it is shown with its source.') }}
  5. {{ _('Analyze (AI). A model writes a short summary, preconditions, action and an urgency score for a typical web server, using only the collected facts and a strict JSON schema. Fixed versions it mentions are checked against source data in code. AI text is always labelled.') }}
  6. {{ _('Translate. The site is available in several languages. AI summaries are machine-translated from English; original CVE descriptions stay in English.') }}
  7. {{ _('Publish. This site, RSS, JSON API and Telegram (urgent items instantly, the rest as a daily digest).') }}
